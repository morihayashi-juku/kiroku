# kiroku（生徒の記録）

塾の先生用の記録アプリです（iPad mini向け）。

- 生徒ごとの進度・できぐあい・つまずき・定期テストの点数を記録します。
- **データは使っている端末のブラウザの中にだけ保存されます。** このリポジトリやサーバーには送られません。
- バックアップはアプリの「設定 → 書き出す」で行ってください。

## プリント進度ボード（shindo/）

だれがどのプリントをやっているかを管理するアプリです（`shindo/` フォルダ）。

- 生徒ごと・プリントごとに、「次・中・済・再」のはんこで進度を記録します。
- こちらも **データは使っている端末のブラウザの中にだけ保存されます。** リポジトリには送られません。
- バックアップはアプリの「設定 → 書き出す」で行ってください。
