# kiroku（生徒の記録）

塾の先生用の記録アプリです（iPad mini向け）。

- 生徒ごとの進度・できぐあい・つまずき・定期テストの点数を記録します。
- **データは使っている端末のブラウザの中にだけ保存されます。** このリポジトリやサーバーには送られません。
- バックアップはアプリの「設定 → 書き出す」で行ってください。

## プリント進度ボード（shindo/）

だれがどのプリントをやっているかを、**数学（sugaku）・英語（eigo）の教材サイトのデータから自動で集めて**表示するページです（`shindo/`）。

- 組ごとに「今ここ・今の回・これまでの回・記録」、プリント名から「どの組が何回目に使ったか」を出します。
- 教材サイトを更新すれば自動で反映されます。
- 行を開いて「休み」「記録を書く」を押すと、教材棚（sugaku・eigo）の組の記録（log）に直接書きこみます。最初に1回だけ、GitHub の鍵（Fine-grained token・sugaku と eigo の Contents: Read and write）を「設定」に貼ります。鍵はその端末のブラウザの中だけにしまわれます。
- 済のはんこは、教材サイトで付けたチェック（印刷した・木曜済など）を、同じ端末・同じブラウザで読んでいます。
- 教科を足すときは `shindo/index.html` の `SRC` に1つ足します。
